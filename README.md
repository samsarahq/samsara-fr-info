## Service description

The Samsara Connected Operations Cloud is a software-as-a-service platform that connects vehicles, equipment, sites, and workers to provide real-time operational visibility. Samsara IoT devices, including vehicle gateways, dash cameras, and environmental sensors, transmit data to the cloud platform, where customers use applications for fleet telematics, video-based safety, equipment monitoring, driver workflows, and regulatory compliance. The platform provides dashboards, alerting, reporting, and open APIs for integration with customer systems.
